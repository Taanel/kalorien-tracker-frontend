# Kalorien-Tracker – Frontend

Frontend des Kalorien-Trackers, einer Webanwendung, mit der Nutzer Gerichte
mit ihren Kalorien erfassen und einen Überblick über ihre tägliche
Kalorienaufnahme behalten können.

Gebaut mit Vue 3, TypeScript und Vite.

Zugehöriges Backend (Spring Boot): https://github.com/Taanel/kalorien-tracker-backend

## Team

## Aktueller Stand
- Komponente `GerichtListe` zeigt eine Liste von Beispiel-Gerichten (mit `v-for`)

## Starten

```bash
npm install
npm run dev
```

Danach im Browser http://localhost:5173 öffnen.
